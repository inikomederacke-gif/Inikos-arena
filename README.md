# Inikos-arena

3D-Schwertkampfspiel in einer japanischen Arena – 30 Level, Endlos-Modus,
1 gegen 1 gegen Bots oder online, auf Wunsch in der Egoperspektive.

## Herunterladen
- Empfohlen: über den **Iniko Launcher** (installiert und aktualisiert automatisch)
- Oder direkt: die neueste `InikosArena-Setup-….exe` unter **Releases**

Windows zeigt beim ersten Start eventuell „Der Computer wurde durch Windows geschützt“ –
dann auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken.
